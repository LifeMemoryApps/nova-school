NOVA School — Version iPad V8

IMPORTANT
Sur iPad, ne pas ouvrir index.html depuis l’app Fichiers. Les fonctions caméra, micro, stockage et PWA nécessitent une URL web HTTPS.

INSTALLATION RECOMMANDÉE
1. Publier le contenu de ce dossier sur GitHub Pages, Netlify, Cloudflare Pages ou tout hébergement HTTPS statique.
2. Ouvrir l’URL dans Safari sur l’iPad.
3. Toucher le bouton Partager.
4. Choisir « Sur l’écran d’accueil ».
5. Lancer NOVA depuis son icône.

L’app s’ouvrira alors en mode autonome comme une application iPad.
