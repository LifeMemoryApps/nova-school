# NOVA School Premium V6 Focus

Cette version conserve le design Premium V5 et ajoute des fonctions réellement utilisables dans le cours :

- Mode Focus/TDAH facultatif pour réduire la surcharge visuelle sans supprimer les fonctions.
- Mode cours ultra-simplifié.
- Objectif visible et minuteur 10/15/20 minutes.
- Bouton « Je me recentre ».
- Dictée vocale directement dans le cours ouvert.
- Lecture vocale du cours.
- Enregistrement audio lié au cours et conservé dans IndexedDB.
- Marqueur « À compléter » pour ne pas paniquer lorsqu'une partie du cours est manquée.
- Tableau et clavier de symboles mathématiques.
- Scan, PDF, images, annotations, export PDF et partage directement depuis le cours (fonctions V5 conservées).
- Agenda désormais éditable et persistant.
- Correction de sécurité de la migration : une migration échouée n'est plus marquée comme terminée.

## Démarrage Windows
Décompresser entièrement le ZIP puis double-cliquer sur `START_NOVA.bat`.

## Important
Le mode Focus est une option d'interface destinée à réduire les distractions. Il ne remplace pas les recommandations de l'ergothérapeute, de l'équipe pédagogique ou des professionnels qui suivent l'élève.
