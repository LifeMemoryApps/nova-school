NOVA SCHOOL V13 — FOCUS FINAL

Mise à jour GitHub Pages :
1. Décompresser ce ZIP.
2. GitHub > dépôt nova-school > Add file > Upload files.
3. Envoyer le CONTENU de ce dossier à la racine (index.html, manifest.json, sw.js, icons/).
4. Commit changes.
5. Ne rien changer dans Settings > Pages.
6. Attendre le déploiement puis recharger.

Le changement porte surtout sur l’architecture UX : accueil calme, éditeur centré sur la feuille, Focus, navigation compacte et blocs pédagogiques escamotables.
